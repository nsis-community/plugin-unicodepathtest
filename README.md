## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-unicodepathtest/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `UnicodePathTest.dll` to `Plugins/<variant>/`.
